# FutureFund Data Dictionary

## Synthetic Dataset V2

### Overview
This dataset contains synthetic Indian-style financial data. It generates 5,000 distinct financial profiles, mapped to three specific decision universes (Act Now, Wait & Prepare, Reimagine the Plan). The dataset totals 15,000 scenario records.

**Important Notice:** This dataset is purely synthetic. The labels and values are generated systematically based on predefined compounding rules and do not describe actual bank customers or observed real-world behaviors.

### Inputs (Features)
* `record_id`: Unique identifier combining the profile and the universe. **(Do not use as ML feature)**
* `profile_id`: Unique identifier for the base user profile. **(Do not use as ML feature)**
* `universe_id`: Strategy configuration ("act_now", "wait_prepare", "reimagine").
* `monthly_income_inr`: Primary monthly income.
* `other_income_inr`: Additional monthly income sources.
* `monthly_rent_inr`: Fixed monthly rent (explicitly segregated to avoid double-counting).
* `essential_expenses_excluding_rent_inr`: Mandatory recurring living costs.
* `variable_expenses_inr`: Discretionary monthly outflow.
* `current_savings_inr`: Liquid cash reserves available to the user.
* `existing_monthly_emi_inr`: Burden of already-existing debt payments.
* `original_proposed_loan_amount_inr`: The initial loan request (used as a benchmark).
* `configured_loan_amount_inr`: The loan actually modeled for the selected universe (e.g., 70% in Reimagine).
* `annual_interest_rate_pct`: Fixed annual interest rate applied to the loan.
* `tenure_months`: Payback period in months.
* `decision_delay_months`: Strategic waiting period before initiating the loan (e.g., 6 months in Wait & Prepare).
* `upfront_cash_outflow_inr`: Direct lump-sum costs applied exactly at the decision initiation.
* `annual_rent_inflation_pct`: Annual compounding growth factor for rent.
* `annual_essential_expense_inflation_pct`: Annual compounding growth factor for essentials.
* `annual_variable_expense_inflation_pct`: Annual compounding growth factor for variable costs.
* `annual_income_growth_pct`: Annual compounding growth factor for total income.
* `simulation_horizon_months`: The targeted monthly window of the simulation (12, 24, or 36 months).

### Target Variable (Outcomes)
* `financial_stress_label`: Binary label (0 or 1). Derived from simulated outcomes. Marked as `1` if the projected `closing_cash_balance_inr` falls strictly below the `total_monthly_outflow_inr` during any active month within the selected horizon (from month 1 onwards).

## Synthetic Dataset V3 (Primary — 300k scenario records)

### Overview
This is the primary training dataset for FutureFund, generated by ingesting 100,000 base profiles from the existing `FinMultiverse_100k_refined_training_dataset.csv` and re-simulating each through the Phase 2 multi-universe engine.

The source dataset's own `financial_stress_label` is **completely ignored**. All labels are freshly derived from our simulator's actual monthly projections.

### Source and Provenance
* **Source**: `data/source/FinMultiverse_100k_refined_training_dataset.csv` (100,000 synthetic Indian-style profiles).
* **Generator**: `backend/app/ml/generate_data_v3.py`
* **Seed**: 42 (fully reproducible)
* **Profiles used**: 100,000 (0 invalid)
* **Scenario records**: 300,000 (3 universes × 100,000 profiles)

### What was added vs. the source
The source dataset lacks expense-inflation and income-growth assumptions. The V3 generator assigns these deterministically per-profile using a seeded RNG:

| Assumption | Range |
|---|---|
| `annual_rent_inflation_pct` | 0.0 – 10.0% |
| `annual_essential_expense_inflation_pct` | 0.0 – 10.0% |
| `annual_variable_expense_inflation_pct` | 0.0 – 8.0% |
| `annual_income_growth_pct` | 0.0 – 15.0% |

### Output Files
| File | Location | Rows |
|---|---|---|
| Training features | `data/v3/futurefund_training_v3.csv` | 300,000 |
| Simulation outcomes | `data/v3/futurefund_outcomes_v3.csv` | 300,000 |
| Manifest | `data/v3/manifest.json` | — |

### Label Distribution
* **0 (Non-Stressed)**: 251,318 (83.8%)
* **1 (Stressed)**: 48,682 (16.2%)

Labels are NOT manually balanced. The natural skew reflects that many source profiles have comfortable financial margins under our simulation rules. Phase 4 model training should account for this imbalance.

### Leakage Prevention
Training features contain only pre-decision inputs and assigned assumptions. All future outcomes (ending cash balance, minimum cash, breach month, projected totals) are isolated in the outcomes file.

### Split Rule
All three universe rows sharing the same `profile_id` **must** stay together in train/test splits to prevent data leakage across related scenarios.

### Disclaimers
* This is synthetic data. Model performance on synthetic test data does not establish real-world predictive accuracy.
* The financial-stress label is derived from simulated outcomes under specified assumptions, not from observed borrower defaults.
* Source profiles do not represent nationally representative Indian households.
